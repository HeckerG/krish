# E-commerce Customer Behavior Prediction

A complete starter project for exploring customer engagement, analyzing correlations, predicting yearly customer spending, and demonstrating the model through a Streamlit dashboard.

## Research question

How accurately can yearly customer spending be predicted from average session length, time on app, time on website, and membership length?

## Dataset

Use the classic **Ecommerce Customers** dataset. It contains customer engagement measurements and `Yearly Amount Spent`, the continuous target for regression.

- Dataset page / downloadable CSV: https://github.com/sayande01/Kaggle_Notebooks/blob/main/Ecommerce%20Customers.csv
- Direct CSV: https://raw.githubusercontent.com/sayande01/Kaggle_Notebooks/main/Ecommerce%20Customers.csv
- The repository describes the dataset as originating from Kaggle. Cite the original dataset page/repository you actually download from in your submitted report.

Download the CSV and save it as:

`data/Ecommerce Customers.csv`

The CSV also contains identifying columns such as Email and Address. This project does not use them for analysis or prediction.

## Run locally on macOS

Open Terminal, navigate to this folder, then run:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

Download the CSV to `data/Ecommerce Customers.csv`, then start the dashboard:

```bash
streamlit run app.py
```

If `streamlit` is not found, use:

```bash
python -m streamlit run app.py
```

## Run in Google Colab

Colab is useful for the notebook-style analysis, but Streamlit is easiest to run locally or deploy using Streamlit Community Cloud. Upload the CSV to the `data` folder if running locally.

## Files

- `app.py`: interactive dashboard, data validation, EDA, correlation analysis, model training, evaluation, prediction interface.
- `analysis.py`: standalone analysis script that saves summary tables and charts to `outputs/`.
- `report_template.md`: report structure to complete after running the project.
- `requirements.txt`: Python dependencies.

## Method

1. Inspect and validate data.
2. Calculate descriptive statistics.
3. Calculate Pearson correlation.
4. Split data into training and test sets.
5. Compare a mean-only baseline with Linear Regression and Random Forest Regression.
6. Evaluate with MAE, RMSE, and R².
7. Use the selected model to estimate spending for a new profile.

## Important limitations

- This is a small, educational dataset, not a guaranteed representation of every online retailer.
- Correlation does not prove causation.
- Predictions are estimates and should not be treated as guaranteed future spending.
- Report the actual metrics generated by your run. Do not invent or copy results from another implementation.
